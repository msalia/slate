# Getting Started

Create your first event and start building a schedule in under a minute.

## 1. Create Your First Event

Click the **Create Event** button in the top-right corner of the Events page. Fill in:

- **Event Name** — The title of your event (e.g., "Tech Summit 2026").
- **Start Date** and **End Date** — The date range for your event. Single-day events use the same date for both.

Your timezone is detected automatically. After creating the event, you'll be taken directly to the calendar editor.

## 2. Set Up Tracks

Tracks are the columns in your calendar — they represent parallel venues or streams. In the editor sidebar on the right, find the **Tracks** section:

- Type a track name (e.g., "Main Stage") and click the + button to add it.
- Add as many tracks as you need.
- Edit a track name by clicking on it and typing.
- Delete a track with the trash icon (only if no sessions are assigned to it).

## 3. Add Categories

Categories let you color-code your sessions by type. In the editor sidebar, find the **Categories** section:

- Click **New category** to create one.
- Give it a name (e.g., "Talk", "Workshop", "Panel") and pick a color.
- Categories are saved to your account and can be reused across events.

## 4. Add Presenters

Navigate to the [Presenters](/presenters) page from the sidebar to build your roster. Each presenter has:

- **Name** — Their display name.
- **Role** — Their title or position (optional).
- **Bio** — A short biography shown to attendees (optional).

You can also quick-add presenters from the editor sidebar without leaving the calendar view.

## 5. Build Your Schedule

With tracks, categories, and presenters in place, you're ready to add sessions to the calendar. See the [Calendar Editor](/docs/calendar) guide for details on creating and managing sessions.

## 6. Publish

When your schedule is ready, open **Event Settings** (gear icon in the editor) and click **Publish**. This generates a shareable link that attendees can use to view the schedule. See [Publishing](/docs/publishing) for more details.
