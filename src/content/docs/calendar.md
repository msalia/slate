# Calendar Editor

The calendar editor is the heart of Slate — a visual grid where you build your event schedule by creating and arranging sessions across tracks and time slots.

## Layout

The editor is split into two areas:

- **Calendar Grid (left)** — The main area where sessions appear as cards on a time-based grid. Time runs vertically (top to bottom), and tracks are columns.
- **Sidebar (right)** — Manages tracks, categories, and presenters for this event. You can add, edit, and organize them without leaving the editor.

## Tracks

Tracks are the columns in your calendar. They represent parallel venues, rooms, or streams at your event. Common examples:

- Main Stage / Workshop Room / Breakout A
- Technical / Business / Design
- Beginner / Intermediate / Advanced

Add tracks from the sidebar. Each track becomes a column in the calendar grid. You can rename tracks inline and delete them if no sessions are assigned.

## Categories

Categories are color-coded labels that help distinguish session types. Each category has a name and a color from the predefined palette (blue, green, orange, purple, pink, teal, red, yellow).

When you assign a category to a session, the session card displays a colored border matching the category color. This makes it easy to scan the calendar and identify session types at a glance.

Categories are saved to your account and can be reused across events. From the sidebar, you can create new categories or link existing ones to the current event.

## Sessions

Sessions are the individual entries on your calendar. Each session has:

- **Title** — The session name.
- **Start & End Time** — Determines the position and height on the grid.
- **Track** — Which column the session appears in.
- **Category** — Optional color-coding.
- **Description** — Detailed information shown to attendees.
- **Presenters** — One or more presenters from your roster.
- **Break** — A toggle that marks the session as a break (coffee, lunch). Break sessions display with a distinct visual style.

## Event Settings

Click the gear icon in the editor header to open Event Settings. From here you can edit the event name, dates, timezone, and description, as well as publish or delete the event.
