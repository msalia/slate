# Events

Events are the top-level container in CueFlo. Each event represents a conference, meetup, or any scheduled gathering with its own timeline, tracks, and sessions.

## Creating an Event

From the [Events dashboard](/dashboard), click **Create Event**. You'll need to provide:

- **Event Name** — A descriptive name. This is shown to attendees and used to generate the URL slug (e.g., "Tech Summit 2026" becomes `tech-summit-2026`).
- **Start & End Dates** — Defines how many days appear in the calendar editor. Single-day events show one column group; multi-day events show one per day.

The timezone is automatically detected from your browser. You can change it later in Event Settings.

## Event Dashboard

The Events page shows all your events as cards. Each card displays:

- Event name and description
- Date range
- Number of sessions and tracks
- Presenter face pile (avatars of assigned presenters)
- Draft or Published status
- How long ago the event was created

Use the filter tabs (All / Draft / Published) and search bar to find specific events. Click any card to open the calendar editor.

## Event Settings

Inside the calendar editor, click the **gear icon** in the top-right to open Event Settings. Here you can:

- **Publish / Unpublish** — Control whether attendees can see your schedule.
- **Copy Shareable Link** — When published, copy the attendee-facing URL.
- **Edit Details** — Update the event name, dates, timezone, and description.
- **Delete Event** — Permanently remove the event and all its data.

## Event Status

Events have two states:

- **Draft** — The default state. The schedule is only visible to you in the editor. Attendees cannot access the public link.
- **Published** — The schedule is live. Anyone with the shareable link can view the read-only attendee schedule.

You can toggle between Draft and Published at any time. Changes you make to a published event are reflected immediately — attendees will see the latest version when they refresh.
